==================================================
1. REMOVE PIVOT DOUBLE SHIFT
==================================================

Current Pine configuration:

LEFT_BARS = 5
RIGHT_BARS = 3

Fast pivot mode is the default.

Pine semantics:

ta.pivothigh(high, 5, 3)
ta.pivotlow(low, 5, 3)

A pivot becomes known on the confirmation bar.

The actual pivot candle is:

confirmation_bar - RIGHT_BARS

Apply RIGHT_BARS exactly ONCE.

Never shift a pivot index twice.

Never do:

pivot_index = confirmation - rightBars
AND later
pivot_index -= rightBars

The final pivot index must be exactly:

confirmation_index - RIGHT_BARS

==================================================
2. PIVOT STATE ORDER
==================================================

For pivot highs:

ph_*_2 = older pivot
ph_*_1 = newer pivot

For pivot lows:

pl_*_2 = older pivot
pl_*_1 = newer pivot

When a new pivot arrives:

old _1 -> _2
new pivot -> _1

Do NOT reverse this order.

Do NOT shift state again after loading persisted state.

==================================================
3. INDICATORS MUST BE READ AT ACTUAL PIVOT
==================================================

Pine uses:

macdLine[rightBars]
histLine[rightBars]

when the pivot is confirmed.

Therefore RSI/MACD/HIST values stored for a pivot MUST correspond
to the actual pivot candle.

Do NOT read them from the confirmation candle.

Required:

pivot_bar = confirmation_bar - RIGHT_BARS

indicator_at_pivot = indicator[pivot_bar]

No additional shift.
